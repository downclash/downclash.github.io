v2rayN GeoIP / Geosite 更新与规则集错误排查

v2rayN GeoIP、Geosite 更新后报错时，先确认实际内核、资源路径和分类名称。对照 Xray DAT 与 sing-box rule-set 的区别，检查格式、标签和下载依赖，验证失败时恢复配套文件。

GeoIP、Geosite 更新失败先检查什么？

先核对实际核心、文件格式、加载路径和规则引用的分类。Xray 常用 DAT 数据；现代 sing-box 使用相应 rule-set。文件找不到、格式损坏与分类不存在需要不同处理，不能通过改文件后缀互相替代。

  1. 从首个错误确认缺的是文件、分类还是规则集标签。
  2. 按数据来源检查兼容格式、完整性与所需分类。
  3. 保留原资源和规则，更新后重启相关连接并验证实际出站。

GeoIP、Geosite 与规则集用于按分类匹配 IP 或域名。它们不是节点订阅，也不是更换后自动加速的数据库。更新后出现核心启动失败或规则命中变化时，应先确认当前核心读取了哪种文件，以及配置引用的分类是否存在，再决定更新还是恢复。

sing-box 官方废弃列表注明旧 GeoIP / Geosite 功能在 1.12.0 移除，现代配置应使用相应 rule-set。不能看到名称里也有“geosite”，就把 Xray 的 DAT 文件改名为 SRS；扩展名改变不会转换二进制格式。旧教程必须先与实际核心版本对照。

更新 GeoIP / Geosite 前记录什么？

  1. 当前核心和版本：从启动日志确认，不只看客户端标题。
  2. 实际加载位置：看错误路径或项目资源目录说明，区分便携版、安装版和服务运行用户。
  3. 资源来源：记录下载地址、更新时间及项目提供的校验信息。
  4. 配置引用：保存使用的分类名称、rule-set 标签及路由规则。

优先使用客户端支持的资源更新入口。手动管理时先保留已知可用的一套文件和规则，避免只备份数据库而丢掉与它配套的配置。不要将未经核实的文件覆盖到所有同名目录，也不要用 root 复制一遍来猜核心会读哪份。

Geosite 文件存在，为何分类仍不存在？

Xray 规则中的 geosite:分类名 和 geoip:分类名 引用的是文件内部分类。不同数据项目、不同精简或扩展版本可能包含不同集合；有这个文件不代表有每个网上教程提到的分类。分类引用与资源要求可对照 Xray 路由文档。

例如下面只是 Xray 路由规则结构片段，说明分类引用的位置；缺少入站、出站和完整 routing，不能独立运行。direct-example 也必须对应真实出站标签：

{
  "type": "field",
  "domain": ["geosite:cn"],
  "outboundTag": "direct-example"
}

若日志明确说某分类不存在，应对照数据来源的分类目录，检查拼写、资源版本和所需分类。确认新的数据库包含它后再更新；或者恢复原本有效的规则。不要一边删除报错规则一边声称仍保留相同分流行为，恢复连接与维持策略是两项检查。

检查 sing-box 规则集标签与引用

使用 rule-set 时，先找定义中的标签，再找路由或 DNS 规则对该标签的引用。远程规则还要能在启动或更新时下载；如果下载路径依赖尚未可用的代理，应先处理引导依赖。二进制规则集也有格式与版本要求，应按所用核心和生成工具核对。

以下展示本地规则集条目的形状，不是完整配置。rules-example.srs 是占位路径，文件必须真实存在且格式正确；它不能用 DAT 文件替代：

{
  "type": "local",
  "tag": "rules-example",
  "format": "binary",
  "path": "/path/to/rules-example.srs"
}

在线文档可能已加入新字段。比如远程规则集的下载配置在不同 sing-box 版本中存在迁移要求，复制示例前先查看该字段的引入和废弃版本。GUI 自动生成的规则还应通过受支持入口调整，避免下次启动被覆盖。

验证新规则命中，并准备恢复

更新后先确认核心正常启动，再选一条应命中分类的请求和一条不应命中的请求，记录新连接的目标与出站。仅看文件时间变新或提示“下载成功”，不足以证明实际核心使用了它。内网、企业域名与普通公网目标也应各做一次必要检查。

若出现新的启动或分流问题，恢复更新前配套的资源和配置，并保留失败记录供核对。恢复过程中不要顺手修改节点协议或 DNS；否则难以知道哪项解决了问题。分享日志时可以保留资源路径的必要结构，但隐藏个人目录名、内部域名和订阅信息。

GeoIP、Geosite 与规则集常见问题

把 geosite.dat 改名为 .srs 可以给 sing-box 用吗？

不可以。改名不会转换内部格式。应使用所选核心支持的规则集，或按其迁移文档转换受支持的数据，并核对生成格式与核心版本是否兼容。

提示下载成功，为什么仍报分类不存在？

成功下载只证明取得了文件。实际核心可能读取另一目录，下载结果也可能不含该分类。核对错误中的路径、内部分类名和数据来源，再检查是否需要对应的精简或扩展版本。

更新规则文件就一定能提速吗？

不能保证。规则数据主要影响流量分类与出站选择，速度还受节点和网络链路等因素影响。更新后应验证需要的分流行为，而不是仅比较文件日期或单次延迟。
