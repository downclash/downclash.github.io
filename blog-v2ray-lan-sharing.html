v2rayN 怎样向局域网设备共享代理？

让客户端在可信局域网可达的地址监听，再在另一台设备填写电脑的 LAN 地址和实际代理端口。手机不能把 127.0.0.1 当作电脑地址。启用共享前核对协议、认证和防火墙允许范围，结束后恢复本机监听。

  1. 先确认电脑上的同一代理入口能够正常访问目标。
  2. 按客户端支持设置 LAN 监听、认证及必要入站限制。
  3. 从允许设备验证请求与出站，并确认未授权访问会被拒绝。

局域网共享是让另一台设备使用电脑已经运行的本地代理入口，不是把订阅公开给别人，也不是让电脑自动成为全网网关。本文面向自己的可信家庭或测试网络，电脑上已运行可用的 v2rayN；其他客户端应先确认它是否支持相同的监听和认证功能。

v2rayN 局域网共享前需要准备什么？

在代理电脑上先用本地 HTTP 或 SOCKS 入口完成一条真实请求，确认节点、路由和核心正常。记录该入口的协议、端口、监听地址和电脑当前 Wi-Fi 或以太网的局域网地址。共享前先决定哪台设备可以访问，不面向公共热点或不受信任的同网段设备开放。

Xray SOCKS 入站说明提醒，这类本地代理并不自动为局域网这一段提供传输加密；用户名和密码也不能代替可信网络及访问限制。此教程不配置路由器端口映射，不向公网开放代理，更不需要开放客户端控制 API。跨互联网访问自己的网络，应使用另外设计的受保护连接方式。

局域网代理应该填写哪个 IP 地址？

127.0.0.1 仅代表正在使用它的那台设备。手机填这个地址，连接的是手机自身，不是电脑。代理只监听回环地址时，其他设备无法访问；对外共享需要客户端允许 LAN 连接，并在适当地址上监听。

若支持绑定具体地址，优先选择需要共享的局域网接口。0.0.0.0 表示广泛监听，不能作为另一台设备要连接的目标地址；实际暴露范围还受核心实现和 IPv6 监听影响。按核心监听说明核对实际地址：多网卡电脑还可能同时连接企业网络，必须核对监听范围，不能只看“允许局域网”开关。

配置 v2rayN LAN 监听、认证与防火墙

  1. 记录当前仅本机使用的配置，进入客户端支持的 LAN、监听或本地入站设置。菜单名称随版本变化，不直接修改可能被重写的临时配置。
  2. 启用所需的 HTTP、SOCKS 或混合入口，保留实际端口，绑定合适的局域网地址。仅启用明确要用的协议。
  3. 客户端支持时为入站配置独立认证信息，不使用订阅密码或节点 UUID 作为共享密码。Xray 的 SOCKS 入站具有密码认证选项；GUI 是否暴露它需看当前版本。
  4. 在系统防火墙中仅允许这个程序或端口的必要入站，并限制为可信网络、指定设备或所需子网。不要通过关闭整个防火墙排查。
  5. 重新加载后确认监听地址与端口确实变化，并核对电脑当前 LAN 地址没有因为切换网络而改变。

如果 GUI 无法提供足够的绑定、认证或访问限制，不应在不可信网络上直接共享。可以保留本机监听，先在可信隔离测试环境研究独立入站配置。

手机和其他电脑怎样填写 HTTP 或 SOCKS 代理？

在目标应用或设备的代理设置里，填写代理电脑的 LAN 地址与实际 HTTP / SOCKS 端口。例如电脑地址为 192.168.50.10、HTTP 端口为 10809 时，目标是 http://192.168.50.10:10809。这些都只是演示值，要替换为自己的环境。

手机 Wi-Fi 的“手动代理”通常用于 HTTP 代理，不能因为填了 SOCKS 端口就期待自动兼容。支持认证的应用还需填写相应账号。未提供代理功能的应用、UDP 游戏和全部系统流量不会因此自动接入；这是应用代理共享，不是透明网关。

两台设备须具备互相访问条件。同一 Wi-Fi 名称下也可能启用客户端隔离、访客网络或不同 VLAN；手机热点对设备互访的支持亦需实际验证。

局域网共享怎样验证访问权限？

  1. 先从允许的设备发出测试请求，观察电脑日志是否出现该设备来源地址和目标。
  2. 核对出站和实际网页响应，不能只以端口可连接作为代理成功。
  3. 认证启用后，检查错误密码会失败；不要把请求中的认证内容写进公开截图。
  4. 核对不在允许范围的设备无法使用入口，确认防火墙限制生效。
  5. 让代理电脑睡眠或关闭客户端作一次可解释的对照，确认目标设备理解共享依赖电脑在线。

关闭局域网共享并恢复回环监听

先从目标设备移除这次设置的代理地址，再关闭电脑上的 LAN 共享或恢复回环监听，撤销仅为测试添加的防火墙允许项。保留原有企业与系统规则，不批量删除。再次确认电脑本地代理正常、其他设备已不能访问共享入口，并妥善保存或删除临时认证信息。

v2rayN 局域网共享常见问题

手机代理地址应该填 127.0.0.1 还是电脑 IP？

填写运行代理客户端的电脑 LAN 地址。127.0.0.1 始终表示当前设备自身，手机填它不会连接电脑；0.0.0.0 是监听设置，也不是目标设备应连接的地址。

同一 Wi-Fi 下为什么仍然连不到电脑？

检查电脑监听是否仍限于回环、当前 LAN 地址是否正确，以及防火墙、访客网络或客户端隔离是否阻止互访。同一 Wi-Fi 名称并不能证明两台设备一定可以建立连接。

开启局域网共享后，手机所有应用都会代理吗？

不会。目标应用需要支持并使用填写的 HTTP 或 SOCKS 入口；Wi-Fi 的手动 HTTP 代理也不等于透明接管全部流量。UDP 游戏或不读取该设置的应用需要另行评估支持方式。
