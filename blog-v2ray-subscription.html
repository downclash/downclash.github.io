V2Ray 订阅导入教程：v2rayN、v2rayNG 与 V2rayU 怎么添加节点

V2Ray 订阅导入应区分订阅 URL 与单节点链接。按 v2rayN、v2rayNG 和 V2rayU 的对应入口添加、更新并选择活动节点，再用网页和日志验证连接，遇到空列表时按现象排查。

V2Ray 订阅怎么导入？

V2Ray 订阅 URL 应在客户端的订阅管理中添加、保存并执行更新；vmess://、vless:// 等单节点链接使用剪贴板或扫码导入。节点出现后，再设为活动节点并开启系统代理或 VPN，用目标网页和日志验证连接。

拿到一个链接后，先判断它用于更新一组节点，还是只描述一个节点。把链接粘贴进错误入口，可能出现无法识别、列表为空，或者只导入一次而无法后续更新。本教程适用于 v2rayN、v2rayNG 与 V2rayU；不同版本的菜单名称可能变化，下面以功能而非固定按钮位置说明操作。

V2Ray 订阅链接和节点链接怎么区分？

https://… 可能是订阅地址，也可能只是服务商网站；vmess://、vless://、trojan:// 等通常携带单节点参数。网址能在浏览器打开不等于它是兼容订阅，二维码也只是数据载体，里面既可能放网址也可能放分享链接。

  1. 在配置提供方后台选择当前客户端适用的订阅格式，复制完整 URL，避免漏掉查询参数。
  2. 记下当前客户端版本、可用节点与更新前节点数量；已有配置时先完成导出或备份。
  3. 给订阅使用容易区分的本地备注，例如“个人订阅”；不要在备注里写 token、密码或完整 URL。

订阅 URL 本身可能就是访问凭据。首次测试时只添加一个来源，便于区分导入、更新和联网问题。

在 v2rayN 添加订阅并更新

  1. 打开订阅分组或订阅管理功能，新建一个分组，将订阅 URL 填入地址字段并保存。
  2. 返回列表并选中这个分组，执行更新当前订阅。客户端提供直连与通过代理两种更新方式时，根据订阅服务器可达性选择。
  3. 没有可用代理时，先尝试不通过代理更新。若订阅服务器只能通过已有连接访问，改用一个已验证的活动节点更新。
  4. 更新结束后核对结果提示、节点数量和协议类型。随后将一个节点设为活动服务器，不能只停留在选中一行的状态。

单节点分享链接应使用剪贴板导入等节点入口；导入后检查地址、端口、传输和 TLS 字段。v2rayN 的官方订阅说明还列出内部 v2rayn:// 格式，它可以携带额外配置，但不应推定所有其他软件都支持。

v2rayNG 与 V2rayU 的订阅导入步骤

v2rayNG：在订阅分组功能中新建来源并保存，再执行更新订阅。单个节点可使用客户端支持的分享链接或二维码导入；二维码权限只在需要拍摄扫描时使用。更新完成后选中活动配置，再启动连接并允许 Android VPN 请求。导入操作本身不会让 VPN 自动完成连接。

V2rayU：在当前版本的订阅管理入口添加 URL，更新后从服务器列表选择节点，再开启所需的系统代理或 TUN。V2rayU 的v5 系列发布说明记录了订阅导入和更新相关变更，应按所装版本操作。本文不把某个版本的界面布局作为所有版本的统一入口。

订阅导入后，怎样确认节点和连接正常？

检查项成功迹象不能据此推定
订阅获取更新没有网络或认证错误响应内容一定是所需格式
配置解析列表出现预期节点，字段非空节点仍在有效期且可以连接
活动节点状态显示正在使用目标节点目标应用已接入代理
实际请求目标网页成功，日志显示预期路由所有其他程序也使用相同出口

桌面端可先验证系统代理；Android 需确认 VPN 处于运行状态。测试一个预期代理的目标，再测试一个预期直连的目标；根据日志核对流量进入方式与最终出站。延迟测试成功只证明其对应测试过程成功。

日常更新时保留手动配置与旧连接

订阅中的节点通常由提供方管理，重新更新可能替换、删除或重命名记录。需要长期保留的手工节点和自定义设置，应按客户端支持的方式独立保存，避免把订阅管理的节点当成永久副本。更新后当前活动节点失效时，重新选择有效项再测试。

不必反复更新全部订阅来解决单个网站故障。先区分订阅下载失败、节点连接失败和流量未进入代理；三种现象的处理入口不同。更改更新路径、节点和 DNS 时一次只改一项，并记录结果。

导入时最常见的四种现象

现象优先检查下一步
保存后没有节点是否尚未执行更新，当前是否有分组筛选更新对应来源，再查看全部或正确分组
更新成功但只出现部分节点格式、节点字段与当前内核支持范围与提供方列表对比并查看解析提示
提示无法识别内容拿到的是分享链接、网页还是完整配置使用正确入口或获取匹配格式
节点存在但无法连接活动节点、有效期、核心和代理入口进入连接排查，而非重复导入

恢复与反馈：只保留必要的诊断信息

导入错误来源时，先确认该分组是否还包含手动添加的节点，再按客户端操作移除错误分组或恢复备份。不要为了清空一条错误订阅而直接删除整个数据目录。关闭连接后，清除本客户端设置的系统代理或停止 VPN / TUN，确认直连恢复。

求助时提供客户端、核心版本、更新方式、时间、错误码及脱敏后的结果摘要即可。若完整订阅链接已公开，应在提供方支持的情况下重新生成令牌；只删除公开帖子并不等于旧链接失去访问能力。

V2Ray 订阅导入常见问题

订阅地址和 vless:// 节点链接能填在同一入口吗？

应按当前客户端提供的入口区分。订阅管理需要能够获取配置的地址；单节点分享链接描述一条连接。把分享链接当成下载地址，可能在请求或解析阶段失败。先核对链接类型，再按上文步骤导入。

订阅更新成功后，还要手动选择节点吗？

要确认当前活动节点。更新成功表示配置已被下载和解析，不能证明新节点已经启用。选择有效节点后，开启目标应用所需的系统代理、VPN 或 TUN，再检查实际请求；列表有节点与应用联网是两项检查。

同一订阅能在电脑和 Android 上使用吗？

取决于订阅返回格式、节点参数及两端客户端版本是否兼容。优先获取配置提供方为各客户端生成的入口。即使两端成功导入相同节点，路由、DNS、分应用设置和系统权限也要分别验证。

下一步：先完成一个订阅、一个活动节点和一次实际网页请求；节点为空或更新报错时，转到订阅失败排查，连接失败则检查流量入口和核心日志。
