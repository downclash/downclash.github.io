v2rayN 系统代理设置：自动配置、PAC、路由与退出恢复

v2rayN 系统代理只影响读取相应设置的应用。核对自动配置、PAC、本地监听端口和核心路由，用显式请求与日志定位未生效原因，并在退出后恢复本客户端设置的代理条目。

v2rayN 系统代理怎么设置才会生效？

先确认节点能连接，再让系统代理指向 v2rayN 的实际本地入口。通过客户端启用系统代理后，核对系统中的地址、协议和端口，并用浏览器的新请求与客户端日志验证。系统代理负责接入，路由规则决定接入后的出口；只切换“全局”路由不会自动代理所有程序。

  1. 从客户端读取真实 HTTP 或混合入口，确认核心正在监听。
  2. 启用系统代理，检查浏览器有没有独立代理或绕过设置。
  3. 请求进入日志后再判断出站；退出前清除客户端设置的代理。

v2rayN 系统代理、PAC 和路由有什么区别？

系统代理向愿意读取该设置的应用提供代理地址；核心路由在收到连接后，决定走远端节点、直连或其他出站。二者处在不同阶段：系统代理填对了，不代表所有请求都走远端节点；核心选择“全局”路由，也不会让不读取代理的应用自动接入。

PAC 是应用读取的一段代理自动配置脚本，可按请求返回代理或直连。v2rayN 菜单里的“自动配置系统代理”通常表示由客户端写入系统代理设置，不能只凭“自动”两字判断它正在使用 PAC。查看操作系统实际启用的是手动地址还是自动脚本地址，再核对当前版本的系统代理与路由说明。

Windows、macOS 如何启用并核对系统代理？

  1. 保存原有系统代理、自动配置脚本及企业网络要求。暂时关闭其他会修改代理的客户端，避免两套程序反复覆盖。
  2. 在 v2rayN 选择一个活动节点，确认核心没有启动错误。从客户端设置读取实际 HTTP、SOCKS 或混合入口，不套用网上的默认端口。
  3. 通过客户端的系统代理入口启用代理，再打开操作系统代理设置核对。Windows 可按 Microsoft 的代理设置说明在“设置 → 网络和 Internet → 代理”查看；macOS 在当前网络服务的详情中查看代理项目。
  4. 检查地址指向本机监听入口、端口一致，自动配置脚本没有与手动配置发生意外叠加。若网络配置由组织管理，应按组织要求处理。
  5. 用读取该系统设置的浏览器发起一条新的请求，观察客户端连接或访问日志，再判断路由结果。

Linux 的图形桌面设置与应用支持情况不同。桌面代理启用后，终端工具仍可能需要独立的代理参数或环境变量；不要用浏览器成功推断整个桌面的每个进程都已接入。

用 curl 判断是系统代理还是本地入口的问题

如果浏览器行为不清楚，可先做一次绕开系统代理设置的对照。以下示例假定 HTTP 入口是 127.0.0.1:10809；这是演示值，运行前必须换成设置中真实的 HTTP 或兼容混合端口。Windows 建议调用 curl.exe，避免旧 PowerShell 的同名别名。

curl --noproxy "" --proxy http://127.0.0.1:10809 --head --max-time 15 https://example.com

--noproxy "" 用于本次显式代理测试，避免环境中的 NO_PROXY / no_proxy 绕过列表使请求改走直连；它不会改变客户端路由规则。

example.com 只是测试目标占位。显式代理请求成功，而同一目标的浏览器请求未进入日志，应优先检查浏览器扩展、独立代理、绕过列表与连接缓存。显式请求也失败时，先查本地监听或节点连接，而不是反复切换系统开关。HTTPS 目标通过 HTTP 代理的 CONNECT 隧道访问，代理地址写 http:// 并不要求目标改为明文 HTTP。

v2rayN 退出后断网怎么恢复？

结束使用时，先通过客户端清除它设置的系统代理，停止 TUN，再退出程序。随后验证普通直连站点。如果客户端异常退出，系统仍指向已经关闭的本机端口，浏览器就可能全部报代理连接失败；重新打开客户端执行清除，或在系统中恢复之前记录的地址。

只移除确认由自己设置的项目。公司原有的代理和 PAC 不能随意清空。恢复后重新打开目标应用，必要时重建原有连接再测试；不要通过关闭防火墙或证书检查来修复本地代理指向错误。如果系统代理无法覆盖需要的应用，再阅读 TUN 教程。

v2rayN 系统代理常见问题

“自动配置系统代理”就是 PAC 模式吗？

不能只凭菜单中的“自动”判断。它也可能表示客户端自动写入固定代理地址。到操作系统查看实际启用的是手动代理还是自动配置脚本，再对照该版本说明；PAC 和核心路由是不同阶段的规则。

浏览器能上网，为什么终端还是不能用？

终端中的工具未必读取桌面系统代理。先用该工具的显式代理参数测试同一目标，再决定是否配置环境变量或 TUN；浏览器成功只说明浏览器的这条请求可用。

关闭 v2rayN 后还需要关闭系统代理吗？

需要确认由客户端设置的代理已清除。如果系统仍指向停止监听的本机端口，网页可能报代理连接失败。优先通过客户端正常清除；已有企业代理的设备应恢复此前记录的组织设置。
