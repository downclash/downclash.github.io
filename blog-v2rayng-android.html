v2rayNG 安卓使用教程：订阅、扫码导入与 VPN 设置

在 Android 上选择 v2rayNG APK、导入订阅或节点二维码、允许 VPN 连接并设置分应用代理，附订阅为空、后台断开和连接失败的排查表。

资料整理：V2Ray 下载站 · 独立资料站，依据项目文档整理

v2rayNG 是 Android 客户端，项目支持 Xray 与 V2Fly 核心。它可以管理订阅和节点，并通过 Android VPN 接口接管应用流量。VPN 权限只解决本机流量进入客户端的问题，实际连接仍需要可用节点与兼容配置。

开始前准备：可用的订阅或自建节点参数、适合设备的 APK，以及能直接联网的 Wi-Fi 或移动数据。安装与导入阶段不需要开放手机热点，也不需要开启局域网代理共享。

选择并安装 APK

从Android 下载入口前往 2dust/v2rayNG Releases，确认发布标签、文件名与版本一致。优先选择适用的稳定发布；发布页上的 Source code 和 .sig 文件均不是安装包。

文件标记适用设备
arm64-v8a.apk支持 64 位 ARM 应用的手机和平板。
armeabi-v7a.apk需要 32 位 ARM 应用的设备；还应核对系统版本要求。
x86_64.apk / x86.apk相应架构的模拟器或 x86 设备。
universal.apk不确定架构时可选的通用包，文件通常更大。

按系统提示，只给实际用于安装 APK 的浏览器或文件管理器授予“安装未知应用”权限。升级时保持原渠道和签名；若提示签名冲突，先备份配置并查明原因，避免直接卸载造成配置丢失。项目另有 F-Droid 构建，选择前阅读其发布说明，不应把变体名称等同于特定网络功能。

订阅 URL、分享链接与二维码如何导入

订阅 URL：保存后还要更新

  1. 复制配置提供方给出的完整订阅 URL。进入“订阅分组设置”或对应订阅管理入口，新增分组并填写备注和 URL。
  2. 保存后返回列表，选择该分组，再执行“更新订阅”。更新成功后检查列表中是否出现节点。
  3. 没有节点时，核对链接有效期、账户状态、返回格式与当前网络；不要把服务商登录页面 URL 当作订阅。

单个节点：使用剪贴板或二维码入口

复制 vmess://、vless://、trojan:// 等完整分享链接，在“+”菜单选择“从剪贴板导入”。二维码本质上是承载文本：节点二维码使用“扫描二维码”导入，扫描到订阅 URL 时需确认应用识别为订阅并完成分组保存与更新。扫码成功不等于订阅已更新。

只在使用摄像头扫描时授予相机权限。导入后核对协议、地址、端口和 TLS 等参数；Clash YAML、sing-box JSON 与节点订阅不是同一种格式，兼容性见配置文档。

选择节点、允许 VPN 并验证连接

  1. 点选一个节点，确认其已被选中；需要时先执行客户端的真实连接或延迟测试。
  2. 在设置中确认使用 VPN 模式，点击连接按钮。首次连接时，阅读并允许 Android 的 VPN 连接请求。
  3. 确认客户端显示运行状态、系统出现 VPN 标识，并查看日志中有无核心启动或握手错误。
  4. 打开需要代理的目标网站，再测试应当直连的网站；最后单独检查目标应用，避免仅凭 VPN 标识判断成功。

节点测试成功只覆盖测试请求；低延迟不一定意味着高带宽，也不保证所有站点可用。可在相近时段对同一目标做小流量测试，比较 Wi-Fi 与移动数据结果，定位网络差异。

VPN 模式与“仅代理”模式：VPN 模式用于接管本机应用流量；“仅代理”模式主要提供本地 HTTP / SOCKS 入口，需要在使用方手动配置地址和实际端口。Android 上的其他 VPN、使用 VPN 接口的防火墙或广告过滤工具可能与当前连接互斥。

分应用代理与后台运行

需要只代理少数应用时，进入设置中的分应用代理功能，先确认当前是“选中应用走代理”还是“选中应用绕过代理”。选中清单的含义取决于该开关，设置后重新连接并分别测试一个选中应用与一个未选中应用。应用选择解决接管范围，域名和 IP 路由仍决定已接管流量的出口。

锁屏后频繁断开时，先查看系统是否限制后台运行、电池使用或自动启动。只针对该应用按需调整，并通过锁屏后恢复的实际测试确认效果。自动更新订阅需要可用网络与后台执行条件，不能替代连接状态检查。

按现象排查与恢复

现象先检查修复后的结果
APK 无法安装架构、Android 版本、存储空间及旧包签名；重下原发布文件核对完整性。系统正常完成安装或原渠道升级。
更新成功但列表为空当前订阅分组、格式、账户到期情况，确认没有仅导入 URL 而漏做更新。正确分组中出现可选节点。
点击连接后立即停止VPN 权限、另一款 VPN 是否运行、日志中的配置或核心错误。服务保持运行，VPN 连接持续存在。
VPN 已连接但应用不可用当前节点、分应用名单、路由、DNS、TLS 参数与设备时间。目标请求被正确接管，日志无连续连接错误。
仅移动数据失败同一节点在 Wi-Fi 的结果、IPv4 / IPv6 差异与运营商网络；每次只改一项。能明确复现差异，再针对节点或 DNS 配置处理。
锁屏后断开后台与省电限制、客户端日志、网络切换时间。恢复亮屏后目标应用仍能按规则连接。

停止时使用客户端断开按钮，确认系统 VPN 标识消失，再验证直连。若使用过“仅代理”模式，还需移除自己在 Wi-Fi 或应用中设置的本地代理。继续阅读常见问题，或回到教程中心、客户端对比。
