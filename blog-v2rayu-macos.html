V2rayU macOS 使用教程：订阅导入、路由与 TUN 设置

为 Intel 与 Apple Silicon Mac 选择 V2rayU，完成订阅和节点导入，区分系统代理、路由与 TUN，并排查终端不走代理、休眠后断网等问题。

更新于 2026-11-24 · 阅读约 8 分钟

资料整理：V2Ray 下载站 · 独立资料站，依据项目文档整理

V2rayU 是 macOS 图形代理客户端，可以从菜单栏和主窗口管理节点。当前发布版本具备 Xray / sing-box 相关能力、路由管理、TUN 与应用内日志；旧版以 PAC 为主的教程不能完整代表新版界面。需要在多个桌面系统使用同一客户端时，也可比较支持 macOS 的 v2rayN。

开始前准备：确认 Mac 芯片、macOS 版本和配置来源，准备兼容订阅或节点参数。先记录已有系统代理与 DNS，暂时停用其他会接管流量的 VPN，再逐步验证。

选择安装包并首次启动

  1. 打开“苹果菜单 → 关于本机”：显示 Apple M 系列芯片时选 arm64，显示 Intel 处理器时选 64 / Intel 包。
  2. 从Mac 下载入口进入 yanue/V2rayU Releases，核对所选版本对 macOS 的要求并下载对应 DMG。
  3. 打开 DMG，将应用拖入“应用程序”，再从“应用程序”启动，避免直接在磁盘映像中运行。
  4. 遇到来源验证提示，先重新确认下载来源和文件完整性，再按系统“隐私与安全性”中的应用级提示处理。如果提示含有恶意软件或文件损坏，暂停安装并查看项目当前说明。

安装包、核心与系统版本需要配套。升级前先通过应用可用的备份功能导出配置，保留可恢复副本；订阅、节点密码和导出的配置文件都应私密保存。

导入订阅与单个节点

订阅：管理一组可更新的节点

  1. 打开主窗口的订阅管理入口，新增订阅并填写备注与完整 URL。旧版可能从菜单栏的“订阅设置”进入。
  2. 保存后执行订阅更新；若有导入确认窗口，核对来源、类型和节点数量，再确认导入。
  3. 在服务器列表确认节点已显示，选择要使用的服务器。订阅存在与节点可用是两件事，需要继续完成连接验证。

分享链接：添加单个服务器

复制客户端支持的 vmess://、vless:// 或其他协议链接，使用“从剪贴板导入”；二维码可通过应用支持的扫描或导入入口处理。只有订阅链接才适合放入定期更新的订阅管理，单个节点链接不应当作订阅 URL。

当前版本对 Clash 订阅、Xray 或 sing-box 配置的导入能力与旧版不同，格式和协议支持需核对所装版本的发布说明。导入后检查传输、TLS、SNI 和节点认证信息，不能因节点名称相同就假定参数完整；格式差异见配置文档。

分清系统代理、路由与 TUN

设置决定什么如何使用
系统代理让遵循 macOS 代理设置的应用把流量交给本地核心。首次连接可先启用此方式，确认活动服务器和本地监听端口。
核心路由进入核心的请求走代理、直连还是被拦截。根据实际需求选择路由，结合日志检查命中；“全局”路由不等于所有应用都被接管。
TUN通过虚拟网络接口接管更多应用流量。按应用提示配置所需 helper 和权限；核对 DNS、局域网排除及其他 VPN。
PAC（部分旧版）用脚本决定遵循系统代理的请求如何转发。仅在安装版本仍提供此入口时使用；它不能代表新版全部路由功能。
  1. 选定一个服务器，先启用系统代理，查看应用中核心的运行状态与日志。
  2. 浏览器可正常访问目标后，再按需求调整直连、代理和拦截规则。
  3. 需要接管不读取系统代理的应用时，再启用 TUN。出现内网或 DNS 异常，先关闭 TUN 恢复基线，再逐项调整。

协议支持取决于当前版本与实际使用的核心。不能仅修改协议下拉框就把 VMess 服务端变成 VLESS 或 Trojan，也不要用跳过证书验证处理 TLS 报错。

验证浏览器、终端与退出后的网络

先运行客户端的连接测试，再访问实际目标网站，并访问一个应当直连的网站；同时查看日志或连接页，确认请求确实经过预期出口。客户端延迟测试不代表所有网站的实际速度。

macOS 终端工具不一定读取系统代理。需要单独配置时，从 V2rayU 当前设置读取 HTTP / SOCKS 类型、监听地址和端口，然后按照该命令或应用的代理参数配置。不要照抄其他教程的 1080、1081 等端口，也不要同时留下多个来源的代理环境变量。

结束使用时，先在应用内关闭 TUN 和系统代理，再退出程序；恢复临时修改的终端代理与 DNS。若恢复直连仍失败，到“系统设置 → 网络 → 当前网络 → 详细信息 → 代理”检查是否残留本机代理地址，并与开始前记录的设置对照。

按现象排查

现象先检查修复后的结果
安装后无法打开芯片架构、macOS 要求、原发布文件与系统安全提示；不要在 DMG 内运行。应用正常打开，核心能启动。
订阅导入为空 / 缺少部分节点配置格式、当前版本兼容性、更新日志和单节点必要字段。服务器列表中有参数完整的目标节点。
浏览器可用，终端失败终端是否独立设置代理，代理协议与端口是否一致。终端的实际请求出现在客户端日志中。
TUN 开启后内网不通私有网段、默认出口、企业 VPN、DNS 和路由规则；暂停 TUN 对照。局域网服务可访问，目标公网请求按预期代理。
休眠唤醒后无法连接网络是否已恢复、活动服务器、核心 / TUN 日志及 helper 状态。重新连接后核心持续运行，DNS 与路由恢复。
关闭应用后断网系统代理、本地监听、DNS 和终端环境变量是否残留。恢复原设置后可以直接联网。
